# CampusOne — Unified Campus Operations Prototype

Prototype for BPuT Hackathon 2026 PS07: **How Can Technology Simplify Everyday Campus Life for Students and Administrators?**

Organization context: **Fretbox**

## What this prototype covers

A unified, mobile-responsive campus platform replacing disconnected registers, notice boards, WhatsApp groups, printed forms and separate applications with one digital experience.

### Student experience
- Attendance dashboard and subject-wise attendance
- Timetable with daily schedule and update notices
- Leave requests and gate-pass requests
- Certificate request, tracking and digital verification status
- Hostel complaint reporting and transparent ticket status
- Mess menu and feedback
- Targeted campus notices
- Fee status, payment history and finance queries
- In-app campus assistant for common questions
- Language selector for English, Hindi, Odia, Santali and Nagpuri prototype paths
- Offline/low-bandwidth mode indicator and text-only request fallback

### Administrator experience
- Real-time pending request queue
- Complaint monitoring
- SLA / average resolution-time metrics
- Recurring issue visibility
- Request review actions
- Export queue prototype

## Run

Open `index.html` directly in Chrome/Edge, or serve the folder with any static web server.

No framework, build step or external package is required.

## Important prototype note

The interactions are intentionally front-end/demo based. Authentication, database persistence, real push notifications, institutional APIs, native-language translation models, file uploads, and production AI should be connected during implementation.

The architecture is deliberately simple so a first working hackathon prototype can be demonstrated quickly and extended safely.
